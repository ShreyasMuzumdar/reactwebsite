🛰️ Satellite Tracking Project

Real-time satellite position tracking using MATLAB and Arduino with GUI visualization

Overview

A school project that combines computational modeling with embedded systems to track satellite positions in real-time. Using MATLAB for orbital calculations and Arduino for hardware control, the system displays satellite trajectories and positions on an intuitive graphical user interface.

Key Features

  • Real-time satellite position calculations
  • Orbital mechanics computations using MATLAB
  • Hardware control via Arduino integration
  • Live GUI with position visualization
  • Trajectory plotting and prediction
  • Multiple satellite tracking support
  • Altitude and velocity monitoring

Technology Stack

MATLAB
Arduino
Embedded Systems
Orbital Mechanics
GUI Design

System Architecture

  1. Data Input: Orbital parameters (TLE - Two Line Element data)
  2. Calculation Engine: MATLAB computes satellite position using orbital mechanics
  3. Hardware Interface: Arduino communicates position data to hardware
  4. Visualization: Real-time 3D rendering of satellite position
  5. Tracking: Continuous updates of satellite trajectory

Core Functions

  • Orbital Propagation: Calculates satellite position at any given time
  • Coordinate Transform: Converts orbital to geographic coordinates
  • Visualization: Renders satellite and Earth in 3D
  • Hardware Control: Commands motors for pointing devices

Applications

  • Educational tool for orbital mechanics
  • Satellite observation scheduling
  • Antenna pointing systems
  • Space situational awareness
  • Research in celestial mechanics

Data Sources

  • Two Line Element (TLE) data from NORAD
  • Orbital parameters databases
  • Real-time GPS/GNSS data validation
