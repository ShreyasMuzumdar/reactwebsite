🐍 Python Automations

Useful Python tools for QR code generation and intelligent file management

Overview

A collection of Python automation scripts designed to streamline common tasks. This toolkit includes utilities for QR code generation from text input and intelligent file organization systems that automatically categorize and manage files in your file system.

Tools Included

QR Code Generator

  • Generate QR codes from any text input
  • Support for URLs, contact info, and custom data
  • Customizable QR code size and styling
  • Batch processing for multiple codes
  • Export to multiple formats (PNG, SVG)

File Organization

  • Automatic file categorization by type
  • Intelligent folder structure creation
  • Duplicate file detection
  • File cleanup and consolidation
  • Archive and compress functionality
  • Configurable organization rules
