✋ Hand Tracking Mouse

Control your computer cursor using hand gestures detected by camera

Overview

Hand Tracking Mouse is an innovative input device that uses computer vision to detect hand position and gestures, converting them into mouse cursor movements and clicks. This hands-free interface provides an alternative way to interact with computers, particularly useful for presentations, accessibility, or gaming.

Key Features

  • Real-time hand position detection
  • Cursor movement synchronized with hand movements
  • Gesture recognition for mouse clicks
  • Multi-hand detection and tracking
  • Adjustable sensitivity and smoothing
  • Low-latency performance

Technology Stack

Python
OpenCV
Hand Detection
Computer Vision
Arduino

How It Works

  1. Hand Detection: Camera captures video and detects hand positions
  2. Position Mapping: Hand position is mapped to screen coordinates
  3. Gesture Recognition: Specific hand gestures trigger mouse actions
  4. Cursor Control: System updates cursor position in real-time
  5. Click Actions: Recognized gestures execute mouse clicks

Supported Gestures

  • Open hand: Move cursor
  • Pinch gesture: Left mouse click
  • Two-finger pinch: Right mouse click
  • Peace sign: Scroll wheel

Applications

  • Hands-free computing
  • Accessibility tools for motor impairments
  • Interactive presentations and kiosks
  • Gaming and entertainment
  • Virtual reality interfaces
