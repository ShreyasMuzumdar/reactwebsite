🤖 ShreyAI Voice Assistant

A personalized voice assistant with custom cloned voice powered by local AI models

Overview

ShreyAI is a sophisticated voice assistant that combines a custom-cloned voice with advanced language models to provide natural and personalized voice interactions. Powered by DeepSeek and Ollama, this assistant can run locally on Mac or Raspberry Pi, ensuring privacy and enabling smart device control.

Key Features

  • Custom cloned voice for personalized interactions
  • Local AI model execution (no cloud dependency)
  • Natural language understanding via DeepSeek
  • Smart home device control
  • Cross-platform support (Mac, Raspberry Pi)
  • Privacy-focused architecture
  • Real-time voice processing

Technology Stack

Python
DeepSeek AI
Ollama
Voice Cloning
IoT Integration

Architecture

  1. Voice Input: Captures and processes voice commands
  2. Speech Recognition: Converts audio to text
  3. Language Model: DeepSeek processes commands and generates responses
  4. Voice Synthesis: Custom voice generates natural speech output
  5. Device Control: Executes actions on connected smart devices

Capabilities

  • Conversational AI interactions
  • Smart home automation commands
  • Information retrieval and Q&A
  • Context-aware responses
  • Device status queries
  • Schedule and reminder management

Deployment Options

  • Mac: Native application for macOS systems
  • Raspberry Pi: Optimized for low-power ARM architecture
  • Standalone server deployment
