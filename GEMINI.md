# Project Instructions: React Website

This is a modern personal portfolio website built with React, TypeScript, and Vite.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Language:** TypeScript
- **Animations:** GSAP
- **Icons:** FontAwesome
- **Deployment:** GitHub Pages

## Project Structure
- `src/`: Source code
- `public/`: Static assets
- `dist/`: Build output (ignored by git)

## Workflows
### Development
Run the development server:
```bash
npm run dev
```

### Build
Build the project for production:
```bash
npm run build
```

### Linting
Check for linting errors:
```bash
npm run lint
```

### Deployment
Deploy to GitHub Pages:
```bash
npm run deploy
```

## Conventions
- Use Functional Components with Hooks.
- Use TypeScript for all new components.
- Adhere to the existing styling patterns (Glassmorphism, CSS Custom Properties).
