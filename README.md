Welcome to my Website!

This is a modern, responsive personal portfolio website built with React, TypeScript, and Vite, showcasing advanced frontend development skills through a rich collection of interactive visual effects and animations. The website features a comprehensive theme system with seamless light/dark mode transitions, powered by CSS custom properties and React Context. Visual effects include animated geometric patterns rendered on HTML5 Canvas that dynamically respond to user interactions, a sophisticated GlareHover effect that creates mouse-following spotlight animations, floating elements with configurable intensity and direction, and a realistic TypewriterEffect component for engaging text animations. The site is structured into multiple sections including an About Me page with interests grid, technical Skills showcase with categorized expertise, detailed Education & Experience timeline, interactive Projects gallery with filtering capabilities, downloadable Resume section, and a Robots showcase featuring 3D model integration. Built with modern web technologies including FontAwesome icons, the website demonstrates UI/UX design principles with glassmorphism effects, backdrop blur, CSS Grid and Flexbox layouts, and comprehensive responsive design that adapts seamlessly across desktop, tablet, and mobile devices. The codebase follows React best practices with TypeScript for type safety, modular component architecture, and optimized performance through hardware-accelerated animations and accessibility considerations including support for reduced motion preferences.
